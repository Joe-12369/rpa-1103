### 鼠标移动、拖拽组件

#### 一.加载方式

##### 引用DLL：II.RPA.dll

#####  引用类： SDK

#### 二.接口

##### 1. 获取鼠标位置

```
public string CapturePosition(int type)
```

入参：type，0：相对于屏幕左上角，1：相对于当前激活窗口

返回值：

```
{"status":1,"message":"","info":"{\"positiontype\":0,\"x\":448,\"y\":313}"}
```

status:接口操作结果，1：成功，0：失败

message：接口操作失败时，该字段会记录错误信息

info：返回坐标信息，在后面的执行中需要将info的内容回传；

##### 2.执行鼠标移动

```
  public string MouseMove(string json)
```

接口说明：执行鼠标移动这个动作；

入参说明：

json：上一步中获取的info的信息

返回值：

```
{"status":1,"message":"","info":""}
```

status:接口操作结果，1：成功，0：失败

message：接口操作失败时，该字段会记录错误信息

info：为空；

##### 3.执行鼠标拖拽

```
 public string MouseDrag(string json)
```

入参说明：

json格式如下：

```
{
    "positiontype":0, 
    "startx":32,
    "starty":117,
    "endx":431,
    "endy":128,
    "mousetype":0,
    "keys":[]
}
```

其中mousetype为鼠标类型，0：左键，1：右键，2：中键

keys为辅助按键的数组，如["ctrl","alt"]

返回值：

```
{"status":1,"message":"","info":""}
```

status:接口操作结果，1：成功，0：失败

message：接口操作失败时，该字段会记录错误信息

info：为空
